# ADR-0014：SVG 图元四角缩放与旋转交互

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-005、FR-013、NFR-004
- 依赖：[ADR-0011](0011-editor-canvas-operations.md)、[ADR-0012](0012-grid-snap-guides.md)、[ADR-0013](0013-node-transform-properties.md)

## 背景

第五批已支持数值方式修改图元位置、尺寸和旋转，但缺少直接在画布上缩放和旋转的可视交互。Vue 和 React 必须共用相同的变换结果，避免工程 JSON 在两端存在差异。

## 决策

1. 共享核心 `packages/core/src/transform-gesture.ts` 实现 `nw/ne/se/sw` 四角手柄的几何变换。Pointer 世界坐标位移经逆旋转得到图元本地分量，按手柄方向增减宽高，调整节点中心以固定对角锚点；输出二维变换的两位小数近似值。
2. 旋转控制点以图元中心计算 Pointer 起终点夹角，允许 Shift 按 15 度吸附。角度保持 `ScadaDocument 0.1.0` 的 -360～360 度范围；不提供脚本表达式或任意 JS 执行。
3. 两端 SVG 视图只负责绘制手柄、Pointer 捕获、合法预览和错误提示。所有候选通过既有 `withNodeTransform` 校验；非法候选不污染文档，PointerUp 调用 `DocumentEditor.updateSelectedTransform` 一次形成原子撤销历史。
4. 取消事件及 Esc 清除临时几何预览；多选不出现单图元控制手柄。工程 JSON、Tag 绑定、Runtime、工业数据和网关安全边界保持不变。

## 风险与取舍

- 仅为单选提供四角和旋转控制点，边中点、固定比例和多选批量变形待后续实现。
- 目前页面边界判断使用未旋转的布局矩形，不强制旋转后像素范围完全位于画布；画布缩放通过 SVG 坐标换算支持。
- Pointer 变化超过允许范围时保留最近一次有效预览；持续快速拖动可能跳过有效中间帧，后续如有必要可引入沿边界的精确约束。
- 手柄几何以小数点后两位保存，存在有限精度近似；需要实际浏览器验收和性能测试。
- 当前阶段仅为本地草稿，尚未开发服务端工程保存、发布或设备写入。

状态待维护者运行 `pnpm run ready` 并完成 Vue/React 交互验收后再评估。
