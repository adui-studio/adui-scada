# ADR-0020：Studio 本地草稿按需自动保存与冲突停写

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-002、FR-013、NFR-004、NFR-006
- 相关决策：[ADR-0018](0018-schema-version-migration.md)、[ADR-0019](0019-local-draft-persistence.md)

## 背景

第十一批提供手动浏览器草稿保存/恢复/清除；刷新仍需显式恢复，尚无自动保存。若直接对每次刷新编辑快照调用 `localStorage.setItem`，可能把未编辑的演示工程、跨标签页较新的草稿或损坏记录覆盖。必须区分**工程内容改变**和选择/预览状态，严格限制写入频率与范围，且不得把浏览器本地存储当作服务端事务。

## 决策

1. **按需开启，刷新重置**：Vue 与 React 均提供「开启自动保存 / 暂停自动保存」入口，默认关闭，每次进入 Studio 需要重新授权开启。已有合法草稿时先告知后续修改会覆盖它，并请求确认；无效草稿禁止开启，不自动删除。启动、刷新、进入页面均不自动恢复草稿。
2. **共享会话规则**：`packages/core/src/local-draft.ts` 的 `LocalDraftAutoSaveSession` 在开启时保存工程 `projectId`、当前 `ScadaDocument 0.2.0` 的标准 JSON 基线与已存储的完整原始记录。将当前工程校验、序列化并与基线比较，只有内容改变才产生自动保存；选择、SVG 拖动预览和未提交编辑不在保存范围内。
3. **防抖窗口**：两端使用相同的约 **1000 ms** 闲置延迟，在下一次工程变更、暂停自动保存、组件销毁时取消旧计时器；超时只保存当时经过校验的文档。立即关闭浏览器可能丢失最后不足 1 秒的修改，本批不承诺页面关闭前同步强制落盘；重要工程仍必须手动保存或导出 JSON。
4. **尽力而为的冲突停写**：每次自动写入前，比较浏览器当前草稿原始字符串与会话开启/上次写入后已知的字符串；不一致即**拒绝覆盖并暂停**。同一 Origin 的其他标签页触发 `storage` 事件时，界面立即暂停自动保存并提示用户核对。被其他页面删除的草稿不应被自动重建。
5. **局限和风险**：浏览器 `localStorage` **没有原子比较并交换（CAS）或可靠事务锁**，读后到写入前仍可能发生竞态；本批只承诺尽力冲突检测与停写，**不承诺严格跨标签页并发安全**。服务器持久化前的乐观锁、版本条件写入、冲突合并和历史快照需单独设计。
6. **手动操作优先**：手动保存成功后更新当前会话已知基线与草稿记录；恢复草稿、清除草稿、成功导入其他工程时自动暂停当前自动保存，避免下一轮定时器把旧工程重新写回。覆盖已有草稿、恢复替换当前画面或清除草稿仍沿用原有确认框。
7. **失败不覆盖**：存储损坏、未知草稿格式、Schema 不匹配、工程 ID 不符、存储读写失败或 2 MiB 超限，都明确报中文错误并停止自动保存。失败不清除原草稿、不修改当前工程；继续支持手动 JSON 导入导出及受控历史 Schema 迁移。
8. **工业隔离**：自动保存不新增 NestJS API、Runtime 编辑行为、PLC/DCS 直连、设备写入或网关指令；浏览器存储未加密，不允许写入工业凭据及秘密。

## 验收与后续

- Core 新增单元测试：未修改不写入、修改后一次保存、撤销回原状态、连续保存、组合/Tag 保真、外部修改与清除冲突、损坏草稿、工程 ID 错误、写入失败及手动保存后重置基线。
- 双框架需人工验证：自动保存默认关闭、已有草稿开启确认、快速连续修改仅写一次、刷新后**不自动恢复**、需要用户确认恢复、跨标签页修改/删除后停写，以及原有手动保存/恢复/清除和 Runtime 无回归。
- 本批不引入依赖或工程 Schema 改动，不实现加密、实时协同、后台发布、历史快照或严格多标签页锁。真实浏览器行为与完整 `pnpm run ready` 在维护者环境执行后再验收 ADR。
