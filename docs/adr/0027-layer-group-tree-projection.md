# ADR-0027：组合图层树的只读投影与会话交互

- 状态：Proposed
- 日期：2026-11-11
- 关联需求：FR-005、FR-006、FR-013、NFR-004、NFR-006
- 参考：[ADR-0022](0022-multi-page-editor-scope.md)、[ADR-0025](0025-node-lock-visibility.md)、[ADR-0026](0026-precise-layer-order.md)

## 背景

V0.2 的 `ScadaDocument 0.2.0` 将每页图元保存在扁平的 `nodes[]` 中，单层平面组合由 `node.groupId` 标记。编辑器已有组合全选、解组和精确图层排序，但当前 Studio 面板每个成员各占一行，缺少可折叠的组标题、组成员层级以及面板内搜索定位。

## 决策

1. 新增框架无关纯函数 `buildLayerTree(nodes, query?)`，从**当前页面**的已验证图元数组按视觉上层优先构建一层组合树：未组合节点作为独立行；相同 `groupId` 的节点归为一条组合标题与其成员，成员按实际图层从上到下排列。一个组合只输出一次，组标题位于其**最上层成员**的位置。
2. 输出类型为 `LayerTreeNode | LayerTreeGroup`，保留原始只读图元引用和组锚点 ID，并提供原成员数、是否存在锁定成员、隐藏成员数、是否层序不连续等展示元信息。此投影**不排序原始 `nodes[]`、不创建真正嵌套组，也不生成需要持久化的树结构**。
3. 兼容旧工程中不连续排列的组合：树中仍显示一个组标题及其所有成员，但以「层序不连续」提示树结构与 SVG 精确穿插层序不能一一对应。只有通过现有共享 `moveLayer` 实际移动该组时，才将成员连续搬运；打开面板、搜索、折叠均不改变工程。
4. 搜索按去除首尾空格后的大小写不敏感文本匹配组 ID、图元 ID、类型及文本/名称属性。匹配组 ID 时显示全组；只匹配成员时保留组标题并过滤成员。搜索时临时展开匹配组，不覆盖用户之前的折叠选择，也不修改撤销历史。普通搜索输入仅作为纯文本比较，既不作为 HTML，也不作为脚本执行。
5. Vue 和 React 各自维护 `layerSearch` 与 `collapsedGroupIds` 会话状态，不持久化到 `ScadaDocument`、浏览器数据库或应用全局状态。切换页面清空搜索；成功导入 JSON 或恢复 IndexedDB 草稿后清空搜索与折叠状态。组折叠/展开不属于可撤销工程命令。
6. 点击组标题或任一成员，仍向共享 `DocumentEditor.select(memberId, shift)` 传入真实图元 ID，由 Core 自动扩展组合全员并处理 Shift 整组多选。图层树根据 `selectedIds` 高亮相应组及成员；从画布选择某成员时自动展开所在组。显式「定位选中图层」清空搜索、展开所属组并滚动到对应**图层面板行**，不修改画布缩放、坐标或工程。
7. 第十八批 HTML5 拖拽与精确排序能力保留：组标题和成员行均使用组成员的真实图元 ID 调用共享 `moveLayer`，移动组员即整体移动组；组内有锁定成员时禁止拖拽，隐藏成员仍可在列表中查找和恢复。所有视图状态均由框架层管理，避免重复实现组合命令。

## 兼容与安全

- `ScadaDocument 0.2.0`、`groupId`、`pages[].nodes[]`、Tag、几何、rules 和原 Dexie 草稿机制不变；无需 Schema 迁移或依赖升级。Vue/React 共用投影与编辑命令，互相导入 JSON 不会产生额外树字段。
- 工业 Runtime 继续读取 `nodes[]` 进行只读 SVG 渲染，不引入 Runtime 对 Studio 图层树的依赖。锁定是防误操作，不是工业设备写权限，不扩展 PLC/DCS 连接或生产写入接口。
- 当前仅支持单层平面组合。多级嵌套、真正的层组对象、图层名称持久化与搜索结果自动居中画布属于后续需求，不能冒称本批已实现。

## 验证

新增共享 Core 图层树用例覆盖上层顺序、非连续组提示、组标题唯一性、成员与组 ID 搜索、隐藏/锁定统计、纯投影不污染工程，以及与编辑器选中/解组/撤销和跨页隔离的联动；维护者还需执行 Windows `pnpm run ready`、React/Vue 浏览器折叠/搜索/定位/拖拽回归，以及 IndexedDB 和 JSON 往返验收。
