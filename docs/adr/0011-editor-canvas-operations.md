# ADR-0011：V0.2 编辑器多选、图层与画布命令

- 状态：Accepted
- 日期：2026-11-09
- 关联需求：FR-005、FR-006、FR-013、NFR-004
- 依赖：[ADR-0009](0009-studio-editor-foundation.md)

## 背景

已有本地图元单选与绝对移动、Label 文字、撤销重做以及 Vue/React JSON 草稿互通。新增缩放、图元新增删除、多选、对齐与图层排序时，如果分别在 UI 实现业务规则，两个框架会出现工程格式和命令历史不一致。

## 决策

1. 在原 `@adui/scada-core/editor` 子入口扩充 `DocumentEditor`，不增加第三方依赖与 Schema 字段；新增 `selectedIds`，最后选中为主选，继续保留旧 `selectedId`。
2. 视图状态（缩放、选择）不写入工程文档。Vue/React 都通过标准 Pointer Events 与 SVG 坐标变换处理缩放后拖动。
3. 移动组采用统一可行位移区间，避免选中图元被分别截断后破坏布局；每次拖动松开只记录一条命令。
4. 新增图元只支持白名单 `tank/pump/pipe/label`，工程内分配唯一 ID，所有新增 Tag 绑定为空；删除、排序、对齐均经 `parseScadaDocument` 再验证。图层是原有 `nodes` 序列顺序，不添加 `zIndex` 字段。
5. 对齐以最后选中的图元为基准，提供六种模式，限制在画布内；多选图层排序保持组内相对顺序。
6. 现有有限历史保存最多 100 份文档；撤销删除后恢复文档，但不自动恢复已清空的临时选中状态。

## 边界与风险

V0.2 仍然只编辑第一页，当前每次文档编辑与 SVG 预览会重建并校验整份 JSON，复杂大画面需要性能验证后再优化。不支持跨页面多选、旋转节点精确边界、多选框、键盘快捷键、服务端持久化或正式发布。所有模拟读数只用于版式预览，客户端不直接与 PLC/DCS 交互。

Vue/React 的人工交互、双向 JSON 往返、新增单元测试和构建结果必须在开发机实际验收，不能只因源代码已提交就标记完成。
