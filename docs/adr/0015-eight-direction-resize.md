# ADR-0015：八方向缩放手柄与旋转单轴投影

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-005、FR-013、NFR-004
- 依赖：[ADR-0014](0014-svg-transform-handles.md)

## 背景

此前 Vue/React Studio 只提供四角缩放与顶部旋转手柄。工业组态编辑过程中常需要单独调整宽度或高度；复用双轴算法直接处理边中点会让未选中的尺寸轴或图元中心随鼠标切线位移偏移。

## 决策

1. 在 `packages/core/src/transform-gesture.ts` 增加 `n/e/s/w` 四个边中点，`RESIZE_HANDLES` 变为顺时针八方向；复用 `ResizeHandle` 类型，增加共享中文 `RESIZE_HANDLE_LABELS` 和 `resizeHandlePosition`。
2. 以图元旋转角的逆矩阵将 Pointer 位移映射到局部轴。每个手柄使用水平、垂直方向系数 -1/0/1，0 代表该轴尺寸不变，严格忽略切线位移。
3. 通过实际宽、高变化的一半得到**局部中心偏移**，再正向旋转成画布坐标，保证相对的角点或边中点固定。数学近似保留两位小数；对零位移或切线位移保持原始属性，避免浮点误差修改高精度值。
4. React/Vue 仅绘制新增控制点及对应单轴光标，继续共享原 Pointer 捕获、预览校验、原子提交与撤销命令。保留原 Schema `0.1.0`、Tag、只读 Runtime 与工业网络隔离。

## 风险和限制

只约束未旋转布局矩形在页面内，旋转后的视觉 AABB 可能外溢；最小尺寸仍为 0.1。暂不新增 Shift 等比例缩放、自动几何吸附、边缘形变、成组变换或跨页面编辑。旧的四角变换在数值舍入时可能有最多约 0.01 单位量级的坐标调整，本批需通过新旧单测与浏览器实际操作验证兼容性。

本 ADR 状态为 Proposed：待执行 `pnpm run ready`、Vue/React 双向 JSON 及交互验收后再考虑正式接受。
