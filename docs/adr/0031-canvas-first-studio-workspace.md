# ADR-0031：组态工作台采用画布优先的专业编辑器布局

- 状态：Proposed
- 日期：2026-11-11
- 关联需求：FR-005、FR-006、FR-013、NFR-004、NFR-006
- 关联决策：[ADR-0028](0028-tdesign-dual-framework-ui.md)、[ADR-0029](0029-brand-theme-v7.md)、[ADR-0030](0030-tailwind-fullscreen-studio.md)

## 背景与竞品参考

原 Studio 将撤销、导入导出、草稿操作、页面管理、图元创建、层序、对齐、属性与 Tag 绑定全部平铺展示，导致操作层级混乱、属性面板先显示低频操作，画布空间被挤压。

参考的成熟工作台分区（仅吸取布局原则，不复制其功能或视觉资产）：

- [Penpot 编辑器界面](https://help.penpot.app/user-guide/first-steps/the-interface/)：页面和图层位于左侧、工作画布居中、属性位于右侧，工具栏独立。
- [diagrams.net](https://www.drawio.com/blog/)：图形库与画布相邻，格式属性按当前元素呈现。
- [Ignition Perspective Designer](https://www.docs.inductiveautomation.com/docs/8.1/ignition-modules/perspective/perspective-designer-interface)：工业项目浏览器、组件库、Tag 浏览器与上下文属性编辑器按职责分隔。完整可停靠窗口和生产 Tag 采集不是本阶段实现范围。

## 决策

1. Studio 采用应用导航、工程工具栏、页面标签、三栏工作区、底部状态栏五层结构；主画布的横向空间优先于侧栏。整体固定动态视口高度，内部各区域独立滚动。
2. 顶部只保留撤销重做、保存草稿、自动保存及“文件与草稿”菜单；导入、导出、恢复、清理采用原有处理函数，收纳到原生可键盘操作的 `details/summary`。页面标签横向滚动，新增、复制、排序、重命名和删除收纳到“页面管理”菜单。
3. 左侧“资源与图层”分成快速添加、水箱/水泵/管道/文本图元库、图层搜索与可滚动图层树；跨页面复制和使用提示进入低频展开区。原生树组选中、拖放排序、搜索及定位节点行为保持不变。
4. 中央画布顶部独立展示页面尺寸、网格/吸附开关、缩放及左右面板显隐按钮。SVG 本体与其既有 Pointer Events、坐标投影及图元命中保持原样，只增加可聚焦的滚动容器和居中工作区，缩放溢出时回退安全左对齐。
5. 右侧属性检查器先显示已选图元、几何属性、文本、Tag 绑定。原来的锁定/隐藏、剪贴板、组合、排序和对齐移动到“高级图元与图层操作”可折叠区域；**所有按钮仍调用既有共享 DocumentEditor 逻辑**。
6. 状态提示和模拟只读警告移至底部状态栏，保持 `role=status` 语义。左右侧栏显隐为 Vue/React 各自的会话状态，不写入 JSON、IndexedDB 或工程命令历史。
7. 工作台布局 CSS 仅保存在 `@adui/tailwind/studio.css`；Vue/React 保留已有 TDesign 深色控件覆盖和 SVG 控制柄 CSS，避免两端重复维护新布局。共享 Tailwind、V7 品牌 Token 和 ADui Normalize 的选择不变。
8. 在窄窗口按 DOM 顺序垂直展示图层、画布、属性，以便键盘导航顺序与视觉顺序一致。当前仅支持基础响应式与显隐，不把多面板自由拖拽/尺寸持久化描述为已完成。

## 兼容与安全

- 不调整 `ScadaDocument 0.2.0`、Tag ID、数据绑定、模拟器、几何命令或工业写入安全规则；不接入 PLC/DCS。
- 原生 `details/summary` 的焦点环、画布滚动区的键盘焦点、按钮的禁用和 `aria-pressed` 状态必须保留。
- 画布仍是工程尺寸有限的 SVG 视图，不宣称已经具有 Penpot 的无限画布、Ignition 的停靠窗口系统或生产工程发布。
- 固定视口布局只禁止整页滚动，不应截断图层树、几何表单及弹出菜单；内容溢出应在所属工作区域内滚动。

## 验证

- 在维护者 Windows 环境执行 `pnpm run ready`，按 React/Vue 各自单独检查格式、Lint、TS 类型、单测、E2E、文档与 Web/Server 构建。
- 分别在两端以约 1920×1080、1440×900、1024×768 和窄屏、125%/150% 浏览器缩放检查：无外层滚动条；图层、画布、属性区滚动正常；左右面板展开/隐藏后画布自动填充；工程菜单在可见区域内可操作。
- 回归：图元添加、选择、多选、图层树拖放与定位、框选、拖动、缩放和旋转、吸附辅助线、Tag 绑定、撤销重做、导入导出、草稿保存和恢复、Vue↔React JSON 往返。
- 本 ADR 为代码设计记录，不能代替运行结果；当前远端环境不能运行完整 pnpm 安装及浏览器验收。
