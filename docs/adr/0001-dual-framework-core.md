# ADR-0001：Vue 与 React 双版本共享 SCADA Core

- 状态：Accepted
- 日期：2026-11-09
- 关联需求：FR-005、FR-006、FR-007、FR-013、NFR-004

## 背景

产品希望在保留 Vue 技术生态的同时以真实项目学习最新版 React，并提供功能对等的两套正式 Web 客户端。

## 方案比较

1. 仅 React：成本较低，但不满足双版本目标。
2. Vue/React 各自复制完整编辑器逻辑：容易造成数据/行为漂移。
3. 共享 TypeScript 无框架 Core、两套 UI/生命周期适配：前期约束较多，但逻辑可复用。

## 决策

采用方案 3。工程 Schema、Tag、编辑器命令、运行时协议和 API SDK 共用；Vue/React 分别负责路由、视图、框架状态与 UI 库。不得为框架引入不兼容工程格式。React 可先行，Vue 按相同规格对齐。

## 代价与验证

需要两套 UI 维护、更多兼容性测试。首个水处理工程必须完成 Vue → React → Vue 与 React → Vue → React 往返，发布和运行数据保持一致。该验收尚未执行。重大替代决策另建 ADR。
