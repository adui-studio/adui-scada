# ADR-0008：按应用作用域隔离环境变量与秘密

- 状态：Accepted
- 日期：2026-11-09

## 决策

1. 使用各应用独立 `.env.example`，根目录仅保存 Docker Compose 的 Web 宿主机端口模板。实际 `.env` 与模式文件不提交，维持零配置默认启动。
2. React/Vue 在 Vite 配置阶段通过 `loadEnv` 读取非公开的 `SCADA_*` 开发配置。V0.1 限制代理地址只能为本机 HTTP，防止把无鉴权模拟服务暴露给公网或工业网络。未来非敏感前端常量可使用 `VITE_*`，但不得存储凭据。
3. NestJS 与本地 SSE 模拟器采用 Node 内置 `loadEnvFile` 读取可选项目 `.env`；验证端口，保持 `127.0.0.1` 安全默认值，Docker 内部网络显式允许 `0.0.0.0`。
4. Docker Compose 仅将 React/Vue 宿主机端口参数化，监听地址仍固定 `127.0.0.1`；生产部署需要独立安全评审。
5. Tauri 发布版继续使用固定的 Vite `desktop` 构建模式和框架无关离线模拟；环境变量不得隐式开启设备数据写入或绕过网络隔离。

## 影响与验证

不添加 dotenv 等新依赖，不改变已有启动端口或 API 接口。新增 `env:check` 并加入 `ready`；配置及安全说明见 [环境变量文档](../ENVIRONMENT.md)。真实生产认证、密钥管理、网关隔离等不是本 ADR 已实现范围。
