# ADR-0024：Studio 会话图元剪贴板与安全剪切粘贴

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-005、FR-006、FR-013、NFR-004、NFR-006
- 关联文档：[ADR-0022](0022-multi-page-editor-scope.md)、[ADR-0023](0023-page-copy-and-reordering.md)、[V0.2 Studio](../V0.2_STUDIO.md)

## 背景

现有编辑器支持页面复制与跨页面选中图元复制，但缺少当前 Studio 内的快捷复制、剪切和重复粘贴。直接在 UI 实现复制容易绕开共享 Parser 的全工程 ID 唯一及同页完整组合校验，且浏览器系统剪贴板包含跨 Origin 授权和恶意数据输入风险。

## 决策

1. 在框架无关 `DocumentEditor` 会话中持有内存剪贴板 `{ nodes, pasteCount }`，由 `EditorSnapshot.hasClipboard` 暴露是否可粘贴。复制与剪切从严格校验的工程副本中抓取选中图元；若选中任意组合成员，自动包含该组全部成员。剪贴板不写入工程 JSON、IndexedDB 或系统剪贴板，不跨标签页共享。
2. `copySelected()` 只保存快照，不改变工程、不产生撤销历史，保留原选中。空选择返回 `false` 且不清除现有剪贴板。
3. `cutSelected()` 在同一次操作中校验并删除整组选中图元，成功后设置剪贴板、清空选中并提交**一条**可撤销的工程历史；失败不改变工程、剪贴板或历史。
4. `pasteClipboard()` 使用现有 `occupiedIds`、`cloneNodes` 为所有粘贴图元/组合分配全工程唯一 ID，保持源布局、图元层序、类型、属性、规则、Tag ID 和组合成员完整性；成功后选中新图元并提交一条撤销历史。没有剪贴板返回空数组，不修改工程。
5. 首次粘贴尝试统一偏移 `(20, 20)`，后续每次成功粘贴在来源坐标基础上递增 20 像素。目标页面接近边界时限制**整个选中集合**的位移，不改变相对位置、尺寸或旋转；当整体矩形包围盒超过画布时原子拒绝。失败不推进偏移计数，且保留剪贴板，可切换到其他页面再粘贴。
6. 切换页面时保留剪贴板，跨页面粘贴仍由共享 Core 保护 ID 和组合；成功导入或恢复工程后清空剪贴板，防止旧工程内容被误用。撤销/重做只影响文档，不撤销内存复制动作；剪贴板使用新的复制或剪切替换。
7. Vue/React Studio 均提供「复制所选」「剪切所选」「粘贴图元」，支持 `Ctrl/Cmd+C`、`Ctrl/Cmd+X`、`Ctrl/Cmd+V`；事件发生于输入框、文本区域、选择控件或可编辑内容时不拦截浏览器行为；无选中时不覆盖系统复制，空剪贴板时不拦截系统粘贴。保留 `Ctrl+Shift+V` 等其他组合快捷键。

## 兼容与安全

- 保持 `ScadaDocument 0.2.0` 和既有 Dexie 草稿事务、人工恢复及按需自动保存机制；复制操作不修改 `state.document`，因而不触发自动保存，剪切和粘贴才构成实际工程变更。
- 剪贴板内容来自当前通过 `parseScadaDocument` 校验的工程，不引入任意 HTML、JavaScript 执行、外部文件或系统剪贴板文本解析，也不暴露真实工业设备写入。
- 粘贴仍受 Schema 全工程图元上限、页面及组合 ID 唯一、目标画布尺寸、Tag 字段与规则结构校验。浏览器会话结束即丢失剪贴板；它不构成可靠备份或工程发布。

## 验收

Core 测试覆盖复制无历史、剪切与粘贴可撤销、连贴偏移与边界、组合完整性、新旧 ID 不冲突、跨页粘贴、不同画布尺寸、失败保持原状态、源属性快照不受后续编辑影响、JSON 不包含剪贴板及导入清理。维护者需要运行完整 `pnpm run ready`，并人工验证 Vue/React 两套交互、文本输入不受快捷键干扰、跨框架工程 JSON 和 IndexedDB 草稿往返。
