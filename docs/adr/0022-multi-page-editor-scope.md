# ADR-0022：多页面 Studio 的编辑作用域与撤销历史

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-002、FR-005、FR-013、NFR-004、NFR-006
- 关联文档：[V0.2 Studio](../V0.2_STUDIO.md)、[ADR-0021](0021-indexeddb-dexie-storage.md)

## 背景

共享 `ScadaDocument 0.2.0` 已允许最多 100 个页面，但 V0.2 的编辑命令、网格吸附与 SVG 预览原先全部假定 `pages[0]`。只在 UI 中切换页面无法保证编辑目标正确，也可能造成撤销历史定位和草稿污染。

## 决策

1. `DocumentEditor` 保留会话态 `activePageId`，由 `EditorSnapshot` 提供给 Vue 与 React。首次创建或成功导入时选第一页；手动切换清空选择，不修改文档、不写入撤销历史、不触发基于文档变化的自动保存。
2. 新建页面与当前页面尺寸一致、图元列表为空；页面 ID `page-N` 自动避开整个工程内的页面 ID、图元 ID 与组合 ID。名称为非空中文文本，长度遵循既有 Schema 的 256 字符限制。总页数最多 100，至少保留 1 页。
3. 页面创建、重命名、删除与图元修改属于工程编辑命令。撤销历史包含前后激活页面的上下文；跨页面撤销/重做应切换到对应编辑页面，删除页面的撤销应恢复所有图元与 Tag 绑定。
4. 原有 `withNodesTranslated`、`withNodePosition`、`withNodeTransform`、`findNodesInRect`、`resolveDragSnap` 与 `svgDataUrl` 增加可选 `pageId` 参数；省略时仍使用第一页，以兼容单页面调用与现有只读 Runtime。
5. Vue/React Studio 共享 Core 的页面命令，通过相同页面导航、创建、重命名和删除交互完成双版本对等。切页要清理正在进行的拖动/几何预览，不跨页面沿用选中图元。

## 安全与持久化

- 工程文件仍采用 `ScadaDocument 0.2.0`，不写入 `activePageId`，不升级 Schema，不保存用户界面的缩放、选中或拖动预览。
- 整份工程文档按 `projectId` 使用既有 Dexie IndexedDB 草稿事务与版本冲突检测；页面切换不创建新的草稿记录，编辑页面内容、删除和重命名会按现有手动或按需自动保存规则存储。
- 删除页面仅在用户确认后操作，禁止清空最后一页；撤销能恢复页面内容。删除后的本地撤销历史不等于持久备份，退出前仍应另行导出 JSON。
- 不更改工业协议、Tag ID、组态脚本权限或工业设备只读边界；没有服务器工程管理、认证授权和正式工程发布。

## 验证

Core 单测覆盖多页面选择隔离、工程级 ID 唯一、页面创建/改名/删除、撤销重做与跨页图元编辑、最多 100 页、非法输入原子拒绝、JSON 双向导入导出；Runtime 单测覆盖第二页 SVG 输出及旧签名兼容。

维护者需要在 Windows 运行 `pnpm run ready` 并分别在 Vue/React 浏览器执行页面导航与草稿恢复验收。源码提交和静态核对不代表已完成浏览器或工业现场验收。
