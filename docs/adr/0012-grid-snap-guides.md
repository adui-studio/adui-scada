# ADR-0012：V0.2 画布网格和图元吸附

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-005、FR-013、NFR-004
- 依赖：[ADR-0011](0011-editor-canvas-operations.md)

## 背景

目前 Vue/React Studio 具备拖动、缩放、框选、图层和对齐操作，但移动时缺少网格与靠近其他图元时的实时吸附引导。将几何判断放在两端 UI 会造成跨框架不一致，改变工程 Schema 又会破坏已通过的 JSON 互通。

## 决策

1. 在现有 Core 新增纯函数 `resolveDragSnap`，通过 `@adui/scada-core/editor` 导出；输入合法工程、选中节点 ID、原始位移与开关，返回统一的 `dx/dy` 和可选辅助线坐标。
2. 网格固定默认 20 个工程单位、吸附容差 6 单位。分别计算水平和垂直吸附，优先选择距离原位移修正最小的可行落点；修正同等距离时优先图元辅助线。
3. 只使用其他未选中图元的旋转轴对齐外接框作为候选；组内节点不能互相吸附。对图元组整体使用同一位移，保持相对位置和边界约束。
4. 网格与辅助线由 React/Vue SVG 视图绘制；两端的预览和提交均使用共享结果。显示开关、吸附开关和参考线不持久化，避免破坏 `ScadaDocument 0.1.0` 的兼容性。
5. 图元移动仍由原 `DocumentEditor.moveBy` 记录一条可撤销命令；不改变 TagStore、Runtime、后端 API 或工业网关边界。

## 取舍和风险

当前为小场景逐帧计算，候选参考点随节点数量增长；性能压测前不宣称适用于大规模画面。旋转外接矩形只保证保守参考线，不提供旋转边线几何精确匹配。吸附距离固定为工程坐标单位，缩放时屏幕像素感知距离不同；后续需要测量后决定是否按缩放比例换算。

本 ADR 对应 PR 仍需 Windows `pnpm run ready`、Vue/React 实际拖动与 JSON 互通验收后再确认实现状态，不代表正式工程发布或工业生产可用。
