# ADR-0002：独立工业网关与只读优先策略

- 状态：Proposed
- 日期：2026-11-09
- 关联需求：FR-003、FR-004、FR-009、FR-010、FR-014、NFR-001、NFR-002、NFR-003

## 背景

直接从浏览器或公共业务 API 管理 PLC 连接，会引入重复连接、失控写入和网络边界扩大等风险。

## 候选方案

1. 前端直接连接工业设备：不推荐。
2. NestJS 内含所有采集驱动：进程耦合过强。
3. 独立 Gateway 负责 OPC UA、Modbus TCP、MQTT，统一 Tag 数据对接平台：推荐。

## 提案

V1 采集只读优先，客户端不得直连 PLC，设备连接与证书在受控网关处理。写入操作必须单独设计服务端权限、审计、现场授权和联锁安全评估，不作为默认功能。

## 待确认与验证

现场网络/设备清单、协议兼容、安全审批、数据质量、断线重连、历史归档和运维责任均待 PoC。现场确认后再将本 ADR 改为 Accepted 或按替代 ADR 记录。
