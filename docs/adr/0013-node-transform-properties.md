# ADR-0013：V0.2 图元位置、尺寸与旋转属性编辑

- 状态：Proposed
- 日期：2026-11-10
- 关联需求：FR-005、FR-013、NFR-004
- 依赖：[ADR-0011](0011-editor-canvas-operations.md)、[ADR-0012](0012-grid-snap-guides.md)

## 背景

Vue/React Studio 已支持图元拖动、对齐、多选和网格吸附，但属性区域只能查看位置与尺寸，无法直接录入宽高或旋转角度。若两端分别实现几何约束和历史提交，会破坏共享编辑器行为的一致性。

## 决策

1. 在 `@adui/scada-core/editor` 中增加纯函数 `withNodeTransform` 与编辑会话方法 `updateSelectedTransform`。只接受当前第一页单选图元的几何修改，属性校验和撤销由 Core 执行。
2. 使用 `ScadaDocument 0.1.0` 的已有 `x/y/width/height/rotation`，无需迁移 Schema。允许合法小数；尺寸范围 0.1～16384、旋转范围 -360～360 度，未旋转布局矩形不得越过页面边界。
3. 表单显式点击“应用几何属性”才提交，一次修改形成单条撤销历史；数值不合法、超出范围、未单选或未知字段均原子拒绝，空/无变化修改不产生历史。
4. 双框架只管理视图输入，不各自实现业务校验；旧的平移/网格吸附保持现有命令语义，不自动吸附数值输入。
5. 不开放可编辑 Tag 绑定或控制指令；Runtime、服务端和工业网关完全不依赖几何编辑器。

## 取舍和限制

仅对未旋转矩形的 `x/y/width/height` 进行页面边界约束；旋转后的视觉外接矩形可能外溢，复杂旋转安全区和拖拽缩放手柄后续单独设计。多选只支持原有整体平移/对齐，不在本批增加批量几何修改。浏览器中的草稿仍需手动导出 JSON，没有服务端保存/发布。

本 ADR 目前为开发分支提议，须由维护者执行 `pnpm run ready` 及 Vue/React 双框架交互测试后再评估状态。
