# V0.1 工具链与默认模板对齐

## 四个参考模板

- React：`tsconfig.json` → `tsconfig.app.json` / `tsconfig.node.json`，Vite+ React 插件。
- Vue：Vue SFC、`@vue/tsconfig`、Node 类型配置、Vue 插件。
- NestJS：`apps/server` 采用默认模板 ESM、装饰器、Nest CLI、Module/Controller/Service、Vitest + Supertest E2E；业务 API 暂未开发。
- Tauri：`apps/desktop` 采用默认模板 Rust 工程、`src-tauri`、权限、窗口、图标，默认加载 React，`--config` 切换 Vue。

本轮不照搬与实际需求无关的模板 Demo、Router、Pinia；Tauri Rust 仅保留最小桌面壳，不注册模板示例 greet 或 opener 插件。

## 依赖基线

`pnpm-workspace.yaml` Catalog 统一所有第三方依赖版本；工作区内部依赖使用 `workspace:*`。TypeScript 6.0.3、Vite+ 1.5.0、Vitest 5.1.0 为本轮配置基线；不声称已经在用户本地环境成功解析和编译。

`pnpm-lock.yaml` 是旧版本锁文件，必须在开发者本机执行 `pnpm install` 并将变化单独审查、提交。不要手工伪造锁文件。

`vp test run` 运行根配置下的 Core、Runtime 与 NestJS 单测；NestJS E2E 通过服务目录独立 Vitest 配置运行。测试 API 统一从 `vite-plus/test` 导入。

NestJS 和 Tauri 的 Node 依赖统一由 pnpm Catalog 管理，Rust crate 独立由 Cargo.toml / Cargo.lock 管理（不属于 npm 依赖，不能放进 pnpm Catalog）。新版 pnpm 与 Cargo 锁文件尚待有联网工具链的 Windows 环境生成、审查。

## 模块边界

Studio / Runtime 共处 `apps/web-react` 或 `apps/web-vue`，但后者不反向依赖编辑器。Gateway 独立进程，浏览器不得直接连接 PLC / DCS。

## 集中式编辑与质量配置（ADR-0005）

唯一的根目录 `.editorconfig` 统一编码、LF、缩进、末尾换行；Rust 源码使用 4 空格缩进。参考 Vue 默认模板格式，不增加独立 Prettier / ESLint 配置，避免同一仓库相互冲突。

`packages/tsconfig` 暴露框架/环境命名入口：

| 配置入口 | 使用方 |
| --- | --- |
| `@adui/tsconfig/react` | `apps/web-react/tsconfig.app.json` |
| `@adui/tsconfig/vue` | `apps/web-vue/tsconfig.app.json` |
| `@adui/tsconfig/nest` | `apps/server/tsconfig.json` |
| `@adui/tsconfig/node` | 根 / React Vite Node 配置 |
| `@adui/tsconfig/vue-node` | Vue Vite Node 配置 |
| `@adui/tsconfig/core` | `packages/core` |
| `@adui/tsconfig/browser` | `packages/runtime` |

所有 TypeScript 配置仅继承语义选项；`include`、`outDir`、`rootDir`、`tsBuildInfoFile` 等必须在消费方定义。TypeScript 的配置相对路径以**声明该选项的文件目录**为基准，不得把应用输出目录放进共享 preset。

`packages/tooling` 提供 `@adui/tooling/format`、`@adui/tooling/lint`、`@adui/tooling/staged`，根 `vite.config.ts` 组合这些配置。依照 Vite+ Monorepo 规则，`vp check` 的 Format/Lint 以根配置为准；React/Vue/NestJS 的 Oxlint 规则通过根 `lint.overrides` 按路径生效。各应用的 `vite.config.ts` 仅保留其框架插件和 Dev Server 配置。

执行：

```powershell
pnpm install
pnpm run config:check
pnpm run deps:check
vp check
pnpm run ready
```

当前仍缺少在 Windows/pnpm 12 与 TypeScript 6 实际安装后运行上述检查的结果；新增共享配置包需要更新并提交锁文件。
