## 目标

在不绑定身份厂商的前提下，使用 OIDC 建立可信主体，复用现有短期可撤销会话和工程 ACL，向 Vue/React 提供同源、统一的服务端工程版本 API。

### 阶段 B：OIDC Relying Party 与 BFF 会话

- [x] 固定 Issuer OIDC Discovery 与元数据安全校验：使用 openid-client 6.8.9，固定 client_secret_basic / RS256、PKCE S256 能力检查、10 秒超时、惰性缓存及 HTTPS/回环 HTTP 边界。Mock Fetch 单测已添加，**Windows 执行待维护者验收**；不代表真实 IdP 联调。
- [ ] Authorization Code 回调与 ID Token 验证（State、Nonce、PKCE S256 的登录发起与一次性事务已实现，回调校验待完成）。
- 登录事务在 PostgreSQL 原子消费；PKCE verifier 使用 AES-256-GCM 加密；浏览器绑定 Cookie 防登录 CSRF。
- 外部 (iss, sub) 必须映射到预先建立且 active 的本地身份；禁止按 email/角色 Claim 自动建用户或分配租户。
- 回调复用 AuthSessionService，设置 HttpOnly/Secure/SameSite=Lax/Path=/ 的 Host Cookie 和 CSRF Cookie。
- Session Guard 同时支持 Bearer 与 Cookie；Cookie 写请求必须验证 Origin、Fetch Metadata 和 CSRF 同步令牌。
- 提供 OIDC start/callback、me、logout；登出只撤销 ADui SCADA 本地会话。

### 阶段 C：服务端工程版本 API

- 扩展 PrismaProjectVersionStore：工程创建、列表、摘要读取、版本列表、版本读取、CAS 追加。
- 工程首次创建、创建者 ACL、首版 Snapshot、水位和成功审计必须同一事务。
- 所有读取/追加在事务内再次验证租户与 ACL；不泄露跨租户资源存在性。
- 只提供保存版本 API，不实现发布指针、发布审批、回滚、删除和设备写入。

### 阶段 D：双框架共享 API Client 与同源代理

- 新增框架无关 @adui/scada-api-client，统一 fetch、Cookie 凭据、CSRF、响应/错误契约。
- React/Vue Vite 都代理 /api 到同一个 NestJS 服务；Docker Nginx 只代理受控 API 前缀，未知路由仍 404。
- 两框架工程 JSON、Tag Schema 和 API DTO 完全一致；离线 IndexedDB 草稿继续保留，网络失败不得清空草稿。

## 明确不做

- 不选择/托管 Keycloak、Authentik、Entra ID 等具体身份产品；本批只实现标准 OIDC Client。
- 不做本地密码、注册、找回密码、MFA、账号邀请、自动用户/租户创建和外部身份自助绑定。
- 不把 email、groups、roles 或客户端字段转换成内部租户/ACL。
- 不存储 IdP Access/Refresh/ID Token，不将内部会话令牌写入 Web Storage。
- 不实现正式发布、发布指针、回滚、报警、历史趋势、工业协议和设备写入。
- 不因 OIDC 开关默认关闭而改变现有健康探针和本机只读 Demo 行为。

## 依赖与验收原则

- 具体 Issuer、Client ID、Secret、Redirect URI、Web Origin 和 AES 密钥由维护者在本地/部署秘密系统配置；不提交真实值。
- 未提供真实 IdP 配置时使用隔离 Mock Issuer 验证协议实现；只有完成真实 Issuer 回调注册、TLS、外部身份映射和双框架浏览器验收后，才可声明企业 IdP 联调通过。
- 每个阶段保持最小改动，发现现有数据库/模块边界不满足时先补测试和 ADR，不临时绕过权限或关闭安全检查。

### 阶段 B 第二小批：OIDC 一次性登录事务（代码已提交，待 Windows 验证）

- 生成 openid-client State、Nonce、PKCE verifier 和 S256 challenge；授权请求固定为服务端 Redirect URI 与 `openid` Scope。
- State 与浏览器绑定 Cookie 仅以 SHA-256 摘要存储；PKCE verifier 使用 AES-256-GCM 加密，State 摘要作为附加认证数据，防止跨事务密文替换。
- 登录事务有效期 5 分钟；回调通过数据库交互事务中的条件 `updateMany` 原子消费，只有一个并发回调可成功。
- 校验固定 Issuer、浏览器绑定、创建时间、过期时间与一次性消费状态；回跳路径仅允许站内绝对路径，拒绝外部 URL、协议相对地址、反斜杠、片段和控制字符。
- 服务仅注册在未挂载的 `ScadaIdentityModule`，尚无 HTTP Controller；OIDC 开关仍 fail-closed。
- 新增 Mock Prisma 单测覆盖授权参数、密文往返、跨浏览器/过期/重复/并发消费、回跳路径和数据库错误映射；**需维护者 Windows 执行 `vp check`、`pnpm run test:unit`、`pnpm run docs:check` 与 `pnpm run ready`**。
