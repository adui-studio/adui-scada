## 最小调用关系

```text
WaterTreatmentSimulator
        |
        v
     TagStore --------> snapshot / delta
        |                      |
        v                      v
   renderSvgPage       Local SSE test harness
        |
        v
   SVG simulated HMI page
```

所有 Core 模块都不依赖 Vue、React 或浏览器 DOM。Node 演示通过 Core 生成安全白名单 SVG；不允许工程规则中携带脚本，也没有任何 PLC 写入代码。

## 本地命令和验收

```powershell
pnpm install
pnpm run test:core
pnpm run docs:check
vp check
pnpm run dev
```

期望：测试全部通过；文档检查零错误；浏览器显示水位/泵/流量变化；模拟断线后状态 `STALE` 且旧值不以正常实时值显示，恢复后回到 `GOOD`。`vp check` 的实际执行结果须在用户本机按现有锁文件复验。

## 环境与验证限制

代码在独立环境 Node.js 22.16.0（**低于仓库要求的 22.18.0**）通过 `--experimental-strip-types` 执行核心单测；使用预装 TypeScript 进行类型检查。原始 `pnpm-lock.yaml` 的 root importer 未展示 `vite-plus` 依赖项，新建工作区可能需要重新生成锁文件。因当前执行环境无法连接 GitHub / npm 且缺少 pnpm 12.18.0，**未运行** `pnpm install`、`vp check`、正式 Web 构建，也未在目标 Windows 机器验证。已实现部分不代表 V1 的 FR 整项通过。
