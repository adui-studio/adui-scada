# ADui SCADA V0.2 · 共享 SVG Studio 第一阶段

- 状态：**开发分支 / 首批可操作原型（非 V0.2 全部功能）**
- 需求：FR-005 局部、FR-002/006/013 的工程互通准备
- 架构：`ScadaDocument 0.1.0` + 独立 `@adui/scada-core/editor` + Vue/React 懒加载 Studio
- 目标：通过实际水处理工程验证共享编辑语义，而不是先实现完整复杂编辑器 UI

## 使用方式

在仓库根目录分别执行 `pnpm run dev:react` / `pnpm run dev:vue`，打开 Web 页面顶部「组态编辑」。默认仍先显示原有的「运行监控」；点击 Studio 后不需要 SSE 服务即可编辑静态演示工程。原 Runtime 的 SSE 仍需 `pnpm run dev:demo`。

Studio 左侧选择图元，中央基于共享 `renderSvgPage` 展示静态模拟预览，叠加 SVG 可交互选中框。左键拖动后松开提交一次移动；右侧可方向微调、显示几何信息与只读 Tag 绑定，Label 支持静态文本修改。工具栏支持撤销/重做、导出 JSON 草稿、导入经过 Schema 校验的 JSON 文件（最多 2 MiB）。

- 编辑结果只保存在当前浏览器页面内；切换出 Studio 会销毁本次内存编辑会话。**重要：切换页面前请手动导出 JSON**。
- `GOOD` 等仅是本地静态模拟预览，不代表当前工业设备值；运行监控与编辑环境职责分开。
- 外部 JSON 校验失败时不会覆盖已有草稿。SVG 输出严格转义，禁止工程脚本执行。
- 当前仍只支持第一页；已扩展节点增删、缩放、对齐、图层排序、Shift 多选和整体拖动。尚无多页面、复杂对齐辅助线、正式工程保存/发布。
- JSON 工程跨框架兼容：维护者已验证 **React → Vue → React** 往返时图元和 Tag 绑定一致；反向 Vue → React → Vue 仍待单独确认。
- 此阶段不接触真实 PLC/DCS，无写入能力。

## 验收步骤

1. `pnpm run ready`：应通过 Vite+ 格式/Lint/类型、Unit/E2E、Vue/React 与 NestJS 构建；**需要本机运行**。
2. React Studio 选中 `tank`，拖动/微调，确认坐标变化且撤销/重做正确；在 Vue 执行相同操作。
3. 编辑 `title` 文案（含 `<` 与 `&`），确认显示为纯文本而不是脚本或标签。
4. React 导出 JSON，Vue 导入并再次导出，再导入 React；反方向重复。确认节点 ID、Tag 绑定和页面大小均保持一致。
5. 使用格式不正确/超过 2 MiB/非法 Schema JSON 检验拒绝导入并保留当前状态。
6. 返回原 Runtime，确认演示 SSE 质量与 `STALE → GOOD` 表现不受 Studio 影响。

本阶段仅面向开发环境；导出 JSON 不等于正式工程发布。V0.2 后续再开发工程存储、图元管理、缩放/辅助线与高级编辑命令。

## 第二批：画布、图元和图层操作

新增（React/Vue 双端界面与共享 Core 同步）：

1. **缩放**：画布顶部 `− / % / +`，50% 至 200%，每次 25% 步进，点击百分比恢复 100%。仅改变视图大小，不修改工程 JSON 中的节点坐标。
2. **添加**：左侧的「+ 水箱 / + 水泵 / + 管道 / + 文本」创建新图元。新图元 ID 按类型自动递增且保证工程级唯一，初始 `bindings={}`，绝不自动关联工业设备。
3. **删除**：右侧「删除所选」，支持多选批量删除，可撤销。
4. **多选**：左侧图元列表或画布 Shift+点击切换选择；按住鼠标拖动已选图元时整体移动，边缘自动将整组位移限制在页面范围内，保留彼此相对位置。
5. **图层**：右侧置顶、置底、上移一层、下移一层。遵循 SVG 节点顺序，后绘制的节点显示在前方；多选时不改变所选节点的相对顺序。
6. **对齐**：选中两个或更多图元后按最后选中的图元对齐，提供左/水平居中/右/上/垂直居中/下六种模式。操作可撤销。

注意：撤销/重做记录**文档变化**，不保证恢复已清除的选择高亮；导入成功会重置历史。离开 Studio 前仍应手动导出 JSON。当前没有登录、正式发布、服务端持久化或生产设备控制权限。

## 第三批：框选与键盘快捷操作

- 空白画布按住鼠标拖动出现青绿色虚线框，松开后选中与框选范围**相交**的节点；支持反向框选。Shift+拖框可追加选择。
- 位移小于 4 个画布单位的操作视为单击：普通单击清除选择，Shift+单击保留选择。框选本身不占用撤销历史。
- 旋转节点使用轴对齐外接框命中，可能包含图形外围空白，并非精确像素命中。
- **快捷键**：Ctrl/Cmd+A 全选；Ctrl/Cmd+Z 撤销；Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；Delete/Backspace 删除；方向键微移 1 单位，Shift+方向键微移 10 单位；Esc 清除选择。
- 输入框、可编辑控件聚焦以及中文输入法组合时，不抢占快捷键；只有 Studio 打开期间监听，Runtime 无编辑快捷键。
- 框选、缩放、选择依然只存在于 UI 会话，不会污染可跨框架导入导出的工程 JSON。

**待验收**：Windows `pnpm run ready`、两套 Studio 的快捷键与缩放框选、工程双向往返、模拟 Runtime 无回归。

## 第四批：网格、图元吸附与辅助线

Studio 画布顶部增加三种独立开关，初始均开启：

- **显示网格**：在原 SVG 预览上覆盖间距为 20 个工程单位的轻量网格；关闭只隐藏网格，不会清空正在编辑的工程。
- **网格吸附**：拖动图元组时，当左/中/右或上/中/下的参考点距离网格线在 6 个工程单位内时，按最近的可行位置吸附；可以独立关闭。
- **图元吸附**：移动图元组接近其他未选中图元的边沿、中心线时自动调整位置并显示橙色垂直或水平辅助线；多选时不会将组内图元作为参考目标。
- 拖动预览和松开提交共享同一个计算函数；只有实际位置变化才产生一条可撤销命令。拖动不改变 Tag 绑定、工程版本和已有 JSON 字段。
- 若缩放画布，网格和辅助线跟随 SVG `viewBox` 坐标，不修改工程 Schema。

图元吸附采用旋转后的轴对齐外接矩形，尚不支持对旋转边本身的精确吸附。本批不实现工程保存/发布或设备写入。
